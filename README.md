# Refined-Storage-Cross-Dimensional
 - Refined Storage Cross Dimensional is a mod that solves the problem of "Refined Storage" being unable to transmit across latitudes.
 - This mod requires the "MixinBooter" mod and the "Refined Storage" mod as prerequisite mods.
